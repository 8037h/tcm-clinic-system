# 项目下载和文件查看指南

本文面向第一次使用 GitHub 的同学，介绍怎样把项目下载到 Windows 电脑，以及怎样查看里面的文件。查看源码可以不用安装 Git；想运行系统，请在下载后继续阅读仓库首页的运行步骤。

## 一、先在 GitHub 网页上查看

1. 打开 [项目仓库首页](https://github.com/8037h/tcm-clinic-system)。
2. 往下看 **Folders and files**（文件和文件夹）列表。
3. 点击文件夹名称，例如 `core`，可以进入文件夹；再点击 `models.py` 等文件名，就能直接在网页中阅读代码。
4. 点击网页上方的 `tcm-clinic-system` 可以返回仓库首页；也可以使用浏览器返回按钮。
5. 首页往下滚动可以看到 `README.md` 显示的下载和运行说明；[项目技术说明](项目技术说明.md)介绍了系统结构和代码知识。

GitHub 网页主要用于浏览仓库文件。单击 Python 代码文件不会自动启动 Django 系统。

## 二、下载到电脑：ZIP 方式

### 1. 下载

1. 打开 [项目仓库首页](https://github.com/8037h/tcm-clinic-system)。
2. 在文件列表上方找到绿色 **Code** 按钮，点击它。
3. 在弹出的菜单中点击 **Download ZIP**。
4. 浏览器会下载一个 ZIP 压缩包。可以点击浏览器右上角的下载按钮查看下载进度，通常也能在电脑的 **下载** 文件夹找到它。

### 2. 解压

1. 打开 Windows **文件资源管理器**，进入 **下载** 文件夹。
2. 找到下载的 ZIP 文件。文件名通常类似 `tcm-clinic-system-main.zip`；浏览器可能在文件名后添加数字。
3. 右键 ZIP 文件，选择 **全部解压缩**，选择保存位置后点击 **提取**。
4. 打开解压后的文件夹，继续进入里面的 `tcm-clinic-system-main` 文件夹，直到看到 `manage.py`、`requirements.txt`、`core` 和 `receptions`。看到这些内容的位置就是**项目根目录**。

建议把解压后的文件夹放在容易找到的位置，例如 `D:\projects\tcm-clinic-system`。具体路径可以由每个人自己决定。

**ZIP 是下载时的代码快照**。仓库后来更新后，已经下载的 ZIP 和解压目录不会自动更新；可以重新下载，或者使用下文的 Git 方式同步代码。

## 三、使用 Git 下载（可选）

已安装 Git 的同学，可以在希望存放项目的文件夹中打开 PowerShell，运行：

```powershell
git clone https://github.com/8037h/tcm-clinic-system.git
```

命令完成后会创建 `tcm-clinic-system` 文件夹。没有安装 Git 的同学直接使用上面的 ZIP 方式即可。

使用 GitHub Desktop 的同学也可以在仓库首页点击 **Code**，选择 GitHub Desktop 打开或克隆，再选择电脑上的保存位置。公开仓库可以克隆；要直接向这个仓库推送修改，需要仓库所有者授予权限。每位成员也可以通过分支、Fork 和 Pull Request 等方式协作。

## 四、在电脑上查看代码

### 方法一：用 VS Code 打开整个项目

1. 如果电脑还没有 Visual Studio Code，可以从其官方网站下载安装。
2. 打开 VS Code，选择 **文件 → 打开文件夹**（英文界面为 **File → Open Folder**）。
3. 选择第二节中找到的**项目根目录**，也就是能直接看到 `manage.py` 的文件夹。
4. 左侧的资源管理器会显示项目文件夹和文件。点击文件夹可展开，点击文件名可在右侧查看代码。
5. 例如依次点击 `core` → `models.py`，可以查看科室、医师、排班等模型；点击 `templates` → `base.html`，可以查看公共页面框架。

VS Code 的 Markdown 预览可以让 `.md` 说明文件更容易阅读；直接查看纯文本也可以。查看文件本身不需要启动网站，也不要求先安装 Python 依赖。

### 方法二：用记事本或其他编辑器

在文件资源管理器中右键 `.py`、`.html`、`.css`、`.js`、`.md` 或 `.txt` 文件，选择 **打开方式**，再选择记事本或代码编辑器。CSV 文件可以用表格软件查看，也可以用文本编辑器打开。

查看代码时使用“打开方式”选择编辑器；双击 `.py` 或 `.ps1` 可能由电脑尝试执行文件。运行系统请按照 [仓库首页](../README.md) 的命令操作。

## 五、主要文件和文件夹是什么意思

| 名称 | 里面是什么 | 建议先看哪里 |
| --- | --- | --- |
| `README.md` | 下载、安装和运行说明 | 仓库首页会自动显示其内容 |
| `docs/` | 项目文档 | `项目技术说明.md` 介绍技术和业务逻辑 |
| `manage.py` | Django 项目的管理命令入口 | 启动、迁移等命令会用到 |
| `requirements.txt` | Python 第三方依赖清单 | 可用记事本或 VS Code 查看 |
| `tcm_clinic/` | 系统的总配置和路由 | `settings.py` 看配置，`urls.py` 看网址对应关系 |
| `core/` | 科室、医师、排班、绩效、统计、日志等 | `models.py` 看数据结构，`views.py` 看页面处理 |
| `receptions/` | 接诊记录功能 | `models.py`、`forms.py`、`views.py` 分别看数据、表单和页面处理 |
| `templates/` | 公共网页模板 | `base.html` 是公共框架 |
| `static/` | 页面样式、JavaScript 和图表资源 | `css/style.css` 看样式，`js/charts.js` 看图表脚本 |
| `research/` | 公开医师出诊信息的调研资料 | 先读采集说明，再看 CSV；数据不会自动导入系统 |
| `.gitignore` | 告诉 Git 哪些本地文件不加入仓库 | 包括本机数据库、附件、虚拟环境等 |

常见文件后缀：`.py` 是 Python 代码；`.html` 是网页模板；`.css` 是网页样式；`.js` 是 JavaScript；`.md` 是 Markdown 说明文档；`.csv` 是表格文本数据；`.txt` 是普通文本。

## 六、想看到运行中的系统

查看代码与启动网站是两个步骤。想在自己电脑上操作系统，请返回 [仓库首页的运行说明](../README.md)，依次安装 Python 和依赖、执行数据库迁移、创建管理员账号，再启动服务器。启动后在**自己的电脑**浏览器打开 `http://127.0.0.1:8000/`。

仓库没有打包项目负责人的数据库、账号和上传附件。每位同学首次迁移时会在自己的电脑创建数据库，管理员也由本人创建；各自的 SQLite 数据不会因为下载或更新代码而自动同步。
